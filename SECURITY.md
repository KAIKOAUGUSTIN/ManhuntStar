# Security Policy

## Supported Versions

Only the latest release gets security fixes. Please update to it before reporting a problem.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please don't report security problems in public issues or public Discord channels.

Report them privately in one of these ways:

- **GitHub**: go to the **Security** tab of this repository and click **Report a vulnerability**.
- **Discord**: join the [Discord server](https://discord.gg/X6P447F7vx), open a staff ticket and choose the
  **CVE** option.

Include the ManhuntStar and Paper versions, what can be done with the problem and the steps to
reproduce it.

- You should get a first answer within 7 days.
- If the report is accepted, the fix comes out in a new release and you're credited in the release
  notes (unless you'd rather not be).
- If it's declined, you'll get an explanation of why.
